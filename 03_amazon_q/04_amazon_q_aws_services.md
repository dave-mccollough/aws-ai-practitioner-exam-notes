# Amazon Q for AWS Services

- Quicksight
  - Used to visualize data
    - Create dashboards, etc
  - Understands natural language
    - Lets you ask questions about your data
  - Create executive summaries based on your data
  - Ask questions about your data

- EC2
  - Provides guidance for what instance types are best suited to your workload
  - You can provide requirements in natural language

- Chatbot
  - Deploy AWS chatbot to MS Teams or Slack
  - Troubleshoot issues, receive billing alerts, etc

- Glue
  - Glue is AWS ETL server
  - Answer questions about Glue, 
  - Troubleshoot issues
