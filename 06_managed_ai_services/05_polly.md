# Amazon Polly 

- Turn text into lifelike speech using deep learning
- Allows you to create apps that can talk

- Advanced Features
  - Lexicons
    - Define how to read certain pieces of text
      - AWS = Amazon Web Services
  - SSML
    - Speech Synthesis Markup Language
      - Markup for your text to indicate how your pronounce it
  - Voice engine
    - Generative, long-form neural, standard
  - Speech mark 
    - Encode where a sentance/word starts or ends in the audio
    - Helpful for lipsyncing or highlight words as they're spoken
