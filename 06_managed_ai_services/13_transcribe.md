# Amazon Transcribe Medical

- Convert medically relarted speech to text (HIPPA compliant)
- Able to transcribe medical terminology
  - Medical names
  - Terminologies
  - Procedures
- Supports real-time(microphone) or batch transcriptions (file upload)
- Use cases
  - Voice applications that allow physians to dictate notes
  - Transcribe phone calls that report on drug safety and side effects

- Amazon Comprehend Medical
  - Detects and returns useful unstructured clinical text
    - Physians notes
    - Discharge summaies
    - Test results
    - Case notes
  - Use NLP to detect persornal health information (PHI)
  - Store documents in S3
  - Analyze realtime data with kinesis firehouse
