# Amazon Bedrock Overview

- Allows you to build Gen AI applications on AWS
- Fully managed service
- Control the data used to train the model
- Pay per use pricing
- Unified API for all models
- Leverage several foundational models
- 'Out of box' RAG and agent features
- Security, privacy, governance and responbsible AI controls built in
- Provides access to several foundation models
- Amazon Bedrock makes a copy of the foundation model for you to tune with your own data
- Your data is not used to train the foundation model
- Build out RAG capabilites or fine tune models
