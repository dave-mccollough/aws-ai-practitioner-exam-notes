# Reinforcement Learning

- Type of machine learning where an agent learns to make decisions by performing actions in an environment to maximize cumilative rewards
- Key Concepts
  - Agent
    - Learner or decision maker
  - Enviromnet
    - An external system the agent interacts with
  - Action
    - Choices made by an agent
  - Reward
    - Feedback from the environment based on the agents actions
  - State
    - Current situation of the environemnt
  - Policy
    - The strategy the agent uses to determine actions based on the state

- How does reinforcement learning work
  - Learning Process
    - The agent observers the current state of the environment
    - Selects actions based on policy
    - The environment transtions to a new state and provides a reward
    - The agent updates the policy to improve future decisions
  - Goal
    - Maximize cumulative rewards over time

- Use cases
  - Gaming
  - Robotics
  - Finance
  - Healthcare
  - Autonomous Vehicles
