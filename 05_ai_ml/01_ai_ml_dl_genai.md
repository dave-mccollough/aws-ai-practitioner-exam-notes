# AI, Machine Learning, Deep Learning, and GenAI

- What is Artfical Intelligence
  - Broad field for the development of intelligent systems capable of performing tasks that require a human
    - Perception
    - Reasoning
    - Learning
    - Problem Solving
    - Decision Making
  - Umbrella term for various techniques
    - Machine Learning
    - Deep Learning
    - Generative AI
  - Use Cases
    - Computer Vision
    - Facial Recognition
    - Fraud Detection
    - Intelligent Document Processing (IDP)

- AI Components
  - Data Layer
    - Collect vast amounts of data
  - ML Framework and Algorithm Layer
  - Model Layer
    - Implement model and train it
  - Application Layer
    - How you serve the model

- What is Machine Learning
  - Type of AI for building methods that allow machines to learn
  - Data is used to improve performance on a specific task
  - Make predictions based on data used to train the model
  - No explicit programming of rules

- AI is not the same as Machine Learning

- What is Deep Learning
  - Uses neurons and synapses to train models
    - Similar to the human brain
  - Process more complex patterns in data than traditional machine learning
  - **Deep Learning** because there's more than one layer of learning
    - Examples
      - Computer Vision
        - Image Classification
        - Object Detection
        - Image Segmentation
      - Natural Language Processing (NLP)
        - Text Classification
        - Sentiment Analysis
        - Machine Translation
        - Language Generation
  - Large amount of input data
  - Requires a GPU

- Neural Networks
  - Nodes are connected together
  - Nodes are organized into layers
  - When a neural network sees a lot of data, it identifies patterns and changes the connections between the nodes
  - Nodes 'talk' to each other by passing data to the next layer
  - Neural networks have billions of nodes

- GenAI
  - Generative AI
  - Subset of Deep Learning
  - Multi-purpose foundation models backed by neural networks
  - Can be fine tuned to fit specific use cases

- Transformer Model (LLM)
  - Able to process a sentence as a whole instead of word by word
  - Faster and more efficient text processing
  - It gives relative importance to certain words in a sentence
  - Understand and generate human like text
  - Trained on vast amounts of text data
    - Books, internet, etc
  - Examples
    - ChatGPT
      - Chat Generative Pretrained Transformer

- Multi-modal Models
  - Does not rely on a single type of input
    - Could be text, images, audio
  - Does not create a single type of output
