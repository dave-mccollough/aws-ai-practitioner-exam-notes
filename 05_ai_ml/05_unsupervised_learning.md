# Unsupervised Learning

- The goal is to discover inherent patterns, structures or relationships within the input data
- The machine must uncover or create groups itself, but humans still put labels on the output groups
- Common Techniques include
  - Clustering
  - Association Rule Learning
  - Anaomly Detection
- Clustering use cases
  - Customer segmentation
  - Recommendation sytems
  - Targeted marketing
- Feature engineering can help improve the quality of the training

- Clustering Technique
  - Used to group similar datapoints together into clusters based on their features
  - Examples
    - Customer Segmentation
