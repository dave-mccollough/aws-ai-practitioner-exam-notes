# Inferencing

- When a model is making a prediction on new data

- Real Time
  - Computers have to make decisions as data arrives
  - Speed is preferred over accuracy
  - Example 
    - Chatbots
  
- Batch
  - Large amount of data that is analyzed at once
  - Used for data analysis
  - Speed of the results is not a concern, accuracy is

- Inferencing at the edge
  - Edge devices are usually devices with less computing power
  - Devices are close to where the data is generated
  - Small Language Model (SLM)
    - Very low latency
    - Low compute footprint
    - Offline capable
    - Local inference
  - Large Language Model (LLM)
    - More powerful model
    -  High latency
    -  Must be online to be accessed
