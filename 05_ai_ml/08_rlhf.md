# Reinforcement Learning from Human Feedback

- Use human feedback to help ML models to self-learn more efficiently
- Theres a reward function
- Human feedback is incorporated into the reward function to more aligned with human goals
  - Models responses are compared to human responses
  - Humans assess the quality of the models responses
- Used throughout GenAI applications
- Significantly improves model performance

- How does RLHF work
  - Data Collection
  - Supervised fine tuning of a language model
  - Build a seperate reward model
  - Optimze the language model with the reward based model
