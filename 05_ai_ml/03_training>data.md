# Training Data

- To train models, we need good data
  - Garbage in -> Garbage out
- Most critical stage of building a good model
- Several ways to model data
  - This will imnpact the type of algorithms used to train the model
  - Labeled vs Unlabeled data
  - Structured vs Unstructured data

- Labeled Data
  - Data includes both input features and corresponding output labels
  - Example
    - Dataset of animal images where each image is labeled with animal types
      - Dog
      - Cat
  - Use Case
    - Supervised Learning
      - Model is trained to map inputs to known outputs

- Unlabeled Data
  - Data only includes input features without output labels
  - Example
    - Collection of images without labels
  - Use Cases
    - Unsupervised Learning
      - Model tries to find patterns or structures in data

- Structured Data
  - Data is in a structured format
    - Rows and Columns
  - Tabular Data
    - Data is arragned in tables with rows representing records and columns representing features
    - Example
      - Customer database with fields such as name, age, total purchase amount
  - Time Series Data
    - Data points collected or recorded at sucessive points in time
    - Example
      - Stock prices recorded daily for a year

- Unstructured Data
  - Data that doesn't follow a specific structure
  - Often includes text heavy or multimedia content
  - Text Data
    - Unstructured text
      - Articles
      - Social media posts
      - Customer reviews
      - Examples
        - Product reviews
    - Image Data
      - Data in the form of images
      - Can vary widely in format or content
      - Example
        - Images used for object recognition tasks
