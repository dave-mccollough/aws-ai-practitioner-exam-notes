# What is Prompt Engineering

- Prompt Engineering
  - Developing, designing, and optimizing prompts to enhance the output of foundation models for specific needs
 
 - Naive prompt
  - Prompt that gives little guidance leaves interpretation open to the model

- Improving prompting techniques
  - Instructions
    - Task for the model to do
    - Description - how the model should perform
  - Context
    - External information to guide the model
  - Input Data
    - The input for which you want a response
  - Output Indicator
    - Output type or format

- Negative Prompting
  - Instruct the model on what to **not** include or do in it's responses
  - Helps to:
    - Avoid unwanted content
      - Reduces chances of unwanted or inappropiate content
    - Maintain focus
      - Helps the model stay on topic
    - Provide more clarity
      - Helps output clearer and more accessible
